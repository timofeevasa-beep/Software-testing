Лабораторная работа №10
Тема: Подготовка проекта для тестирования, работа с системой контроля версий, логирование и отладка.

Описание: 
Проект реализует проверку данных пользователя при регистрации:
- Валидация логина (телефон, email или строка).
- Проверка пароля (длина, кириллица, цифры, спецсимволы, регистры).
- Проверка подтверждения пароля.
- Логирование через Serilog (консоль + файл).
